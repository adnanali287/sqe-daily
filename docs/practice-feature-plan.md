# Practice library and tests

Visual thesis: a quiet exam desk, using the existing paper, mint, dark-green and
red palette, Newsreader headings and DM Sans controls; no new visual identity.

Order: existing masthead, test setup, active question with compact progress and
timer, review/submission, results and worked explanations. Setup and test state
replace each other rather than stacking the entire workflow on one page.

Interaction: choose a mini test or an approved FLK paper, answer with native radio
controls, navigate and flag questions, review unanswered items, then submit.
Timed sessions use absolute deadlines; refresh never grants extra time. Full mocks
lock completed sessions, include a 60-minute break, and withhold explanations until
the entire paper is submitted. Untimed practice is explicitly separate.

Tokens: inherit existing fonts/colours, 4/8/12/16/24/32px spacing, 4px controls,
44px minimum targets, 120ms state transitions, reduced-motion support. Use normal
document flow, unframed bands, restrained rules and stable option geometry.

Critique: a dashboard of test cards, decorative badges and a huge marketing hero
would compete with practice. Revised to a single setup form, one active-question
surface, a numbered navigation grid and a plain results ledger. No gradient,
decorative artwork, new fonts or paid/account flow.

Delivery: technical implementation stays in a draft PR for screen sign-off and
Hark's content clearance. No early-release approvals are inferred from coding
approval. The 49-question preview is isolated; production scheduling is unchanged.
